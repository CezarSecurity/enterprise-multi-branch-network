# enterprise-multi-branch-network
Scalable enterprise network designed in Cisco Packet Tracer featuring multiple branch offices, Vlan segmentation, centralized services, Layer 3 switching, WAN connectivity and security focused network architecture.

Originally developed as part of university coursework and now being continuosly improved as a personal portfolio project with enhanced documentation, network design and security features.
